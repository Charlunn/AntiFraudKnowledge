ClearSource Design System

Typography

The primary font for ClearSource is a modern sans-serif typeface, chosen for its readability and clean appearance. It ensures clarity across all UI elements, from headlines to body text.

Color Palette

The color palette for ClearSource is designed to convey trust and clarity, with a primary blue for key actions and a neutral gray for backgrounds and secondary elements. Accents of green and red are used for positive and negative feedback, respectively.

Buttons

Buttons in ClearSource are designed for clear interaction, with a primary blue for main actions, a secondary gray for less critical actions, and a tertiary style for subtle actions. All buttons have a slight border radius for a modern look.

Input Fields

Input fields in ClearSource are designed for ease of use, with clear labels and subtle outlines. They provide a consistent and clean interface for user input.

Cards

Cards in ClearSource are used to present information in a structured and visually appealing way. They have a subtle shadow for depth and a clean layout for easy scanning.

Modals

Modals in ClearSource are used for focused interactions, such as confirmations or detailed information displays. They are designed to be clear and concise, with a clear call to action.
