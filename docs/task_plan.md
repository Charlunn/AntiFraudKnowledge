# 任务计划

1. **完善用户系统**
   - 补全邮箱/手机号绑定验证流程。
   - 完成个人信息页前端工具组件封装。
   - 实现成就、设置、退出登录等菜单项对应的 API。
2. **成就系统开发**
   - 设计并实现成就数据模型与 API。
   - 前端工具组件封装获取成就列表。
3. **设置与反馈模块**
   - 实现界面语言、主题切换 API。
   - 实现反馈提交接口与文件上传支持。
4. **AI 反诈测试**
   - 封装 `/api/chat/` 接口，接入 AI 评估逻辑。
   - 前端提供统一的聊天工具组件。
5. **反诈闯关**
   - 设计题库与闯关 API，支持关卡与得分统计。
   - 前端封装答题工具组件。
6. **项目文档与标准化**
   - 补全需求分析、接口设计等文档（当前已添加）。
   - 整理 API 调用说明书，重构前端页面时可直接调用。
