# 需求分析

## 项目概述
反诈骗知识学习平台，提供知识图谱展示、AI 反诈测试和闯关答题等功能，支持管理员与普通用户两种角色。

## 用户角色
- **管理员**：后台维护数据，管理用户权限。
- **普通用户**：注册并登录使用平台功能。

## 功能需求
1. **用户系统**
   - 用户注册：填写账号、昵称、密码并确认密码。
   - 用户登录：支持账号、邮箱或手机号登录。
   - 用户信息：登录后在页面右上角显示头像和昵称，悬浮显示下拉菜单，包含个人信息、成就、设置、退出登录。
   - 个人信息管理：查看头像、昵称、反诈等级；绑定/解绑邮箱与手机号；修改昵称和密码。
   - 权限：账号创建默认普通用户，管理员类型需在数据库中手动指定。
2. **知识图谱可视化**
   - 无需登录即可访问初始图谱、筛选图谱及节点详情。
3. **成就系统**
   - 显示用户已达成的成就、完成时间及达成率。
4. **设置与反馈**
   - 切换界面语言、主题（暗/亮）。
   - 反馈：填写意见、上传图片、提供联系方式并提交。
5. **AI 反诈测试**
   - 用户与 AI 聊天，AI 扮演诈骗分子，对用户回答进行评估。
6. **反诈闯关（答题）**
   - 需登录后进行答题闯关。

## 非功能需求
- **安全性**：密码需满足复杂度校验；用户敏感信息需验证。
- **可维护性**：后端 API 需遵循 REST 规范，前后端分离。
- **可用性**：未登录访问受限功能时需跳转到登录页面。
