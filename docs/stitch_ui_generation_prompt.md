# Stitch UI 图像生成提示词

## 项目概述
**项目名称**: 澄源 - 反诈骗知识平台  
**技术栈**: Vue 3 + Nuxt 3 + Tailwind CSS  
**设计风格**: 现代化、扁平化、渐变色、响应式设计  
**色彩方案**: 主色调蓝色（#4F46E5 indigo-600）、渐变背景、深色模式支持

## 页面完成度分析

### 1. 首页 (index.vue) - 完成度: 95%

**页面功能**:
- 展示平台核心价值和功能介绍
- 统计数据展示（用户数、题目数、知识点、防范案例）
- 功能卡片导航（6个主要功能入口）
- 学习进度和成就展示（仅登录用户可见）
- CTA行动召唤（未登录用户）

**UI特点**:
- Hero区域：大标题 + 双色渐变文字（"反诈骗知识平台" + "守护您的财产安全"）
- 统计卡片：4个并列卡片，深蓝色背景（indigo-600），白色文字
- 功能卡片：3x2网格布局，每卡片有图标（SVG）+ 标题 + 描述 + 跳转链接
  - 蓝色：知识测验
  - 绿色：知识图谱
  - 紫色：社区交流
  - 黄色：个人中心
  - 红色：学习资源
  - 深蓝色：AI智能测试
  - 橙色：举报中心
- 学习进度区域：渐进色进度条（绿色85%、蓝色72%、黄色58%）
- 成就卡片：金色奖章图标 + 成就名称 + 描述

**交互逻辑**:
- 功能卡片hover效果：阴影增强（shadow-lg → shadow-xl）
- 按钮hover效果：背景色加深
- 条件渲染：根据登录状态显示不同内容区域

**Stitch提示词**:
```
设计一个现代化的反诈骗知识平台首页，包含：

**页面功能**:

- 邮箱验证
- 密码设置（强度指示器）
- 确认密码
- 同意服务条款checkbox
- 第三方OAuth注册
- 登录跳转链接

**UI特点**:
- 居中卡片布局
- 头部：蓝色圆形背景 + 添加用户图标 + "创建账户" + 副标题
- 表单输入框：

- 底部：登录链接

- 实时密码强度检测（长度、大小写、数字、特殊字符）
- 输入框失焦验证
- 密码匹配检测
- 服务条款必须勾选才能提交
- OAuth注册流程

**Stitch提示词**:
```

## 通用设计规范

### 色彩体系
- **主色调**: Indigo/Blue (#4F46E5 indigo-600, #3B82F6 blue-500)
- **成功色**: Green (#10B981 green-500)
- **警告色**: Yellow (#F59E0B yellow-500, #EAB308 yellow-600)
- **错误色**: Red (#EF4444 red-500)
- **中性色**: Gray (#6B7280 gray-500, #9CA3AF gray-400)
- **文字色**: 
  - 主要文字: #111827 gray-900
  - 次要文字: #6B7280 gray-500
  - 辅助文字: #9CA3AF gray-400

### 间距规范
- 页面padding: 1.5rem (24px)
- 卡片padding: 1.5rem (24px)
- 卡片间距: 1.5rem (24px) / 2rem (32px)
- 元素间距: 0.5rem (8px) / 1rem (16px)

### 圆角规范
- 小圆角: 0.5rem (8px) rounded-lg
- 大圆角: 0.75rem (12px) rounded-xl
- 按钮圆角: 0.5rem (8px) rounded-lg
- 头像圆角: 9999px rounded-full

### 阴影规范
- 卡片阴影: shadow-lg (0 10px 15px rgba(0,0,0,0.1))
- hover阴影: shadow-xl (0 20px 25px rgba(0,0,0,0.1))
- 按钮阴影: shadow-sm (0 1px 2px rgba(0,0,0,0.05))

### 字体规范
- 大标题: text-3xl (30px) / text-4xl (36px), font-bold
- 标题: text-2xl (24px) / text-xl (20px), font-semibold
- 正文: text-base (16px), font-normal
- 小字: text-sm (14px) / text-xs (12px)

### 响应式断点
- 移动端: < 768px
- 平板: 768px - 1024px
- 桌面: > 1024px
- 网格布局: grid-cols-1 md:grid-cols-2 lg:grid-cols-3

### 交互效果
- hover过渡: transition-colors duration-200
- hover阴影: hover:shadow-xl
- hover背景: hover:bg-{color}-50
- 按钮hover: hover:bg-{color}-700
- 卡片hover: hover:shadow-md hover:border-primary-200

### 图标使用
- 使用Heroicons图标库
- 图标大小: w-4 h-4 (16px) / w-5 h-5 (20px) / w-6 h-6 (24px)
- 图标颜色: 跟随文字颜色或独立设置

### 深色模式
- 支持dark:前缀类名
- 背景色: dark:bg-dark-bg (#1F2937)
- 卡片色: dark:bg-dark-surface (#374151)
- 文字色: dark:text-dark-text (#F9FAFB)
- 边框色: dark:border-dark-border (#4B5563)

1. **每次生成一个页面**: 为确保细节准确，建议每次只生成一个页面的UI图像

6. **注明颜色编码**: 明确不同类型、状态使用的颜色方案
7. **参考完成度**: 优先生成完成度高的页面，可作为设计参考
